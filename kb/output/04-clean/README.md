# 清洗 Agent · 工作说明

**成果目录**：`kb/output/04-clean/`
**成果粒度**：每个岗位一份 —— `<岗位id>.md`

---

**什么时候调用**
- 解析 md 产出后，按岗位逐个跑

**怎么工作**
1. 逐行判定是否为广告 / 引流 / 卖课 / 带货 / 标题党 / 跑题
2. 删掉纯广告行（留微信、加群、领资料、报名课程、带货链接），保留有效内容
3. 质量打分 0-100
4. 判定保留 / 丢弃

**要完成的任务**
把广告与低质内容挡在门外，只放行真正有岗位信息的文本。

**要输出什么东西**
`kb/output/04-clean/<岗位id>.md`（每个岗位一份）

内含：保留 / 丢弃各几条、丢弃理由、质量分分布、保留后的文本

**注意事项**
- **只删不改**：不得改写、润色、合并有效内容
- 每次判定必须写理由，不能只给分数
- 分类标签只能用固定枚举：`广告 / 引流 / 卖课 / 带货 / 标题党 / 跑题 / 太短`
- 保留阈值：质量分 ≥ 60 且正文 ≥ 100 字（阈值定义于 `kb/pipeline.config.json` 的 `clean` 段）
