# 质检结果 · 用户运营（it-ops-user）

> 质检 Agent · 2026-10-18 · 抽检 8 / 80 条 · 结论：忠实

## 抽检条目

- `it-ops-user-kp-026`［核心职责］以线下本地30%返利做基础活跃、自营商城20%-25%返利做长效兜底、CPS 40%-50%高返利做增量拉升，三渠道联动运营；专人负责运维，每月统计三大渠道订单占比、抵扣金额、物业分润数据，针对低产出渠道优化运营策略。
- `it-ops-user-kp-059`［典型的一天］用户运营的日常工作以用户为触点展开全盘事项。每天需要处理前台或后台的用户反馈，及时解决用户问题；遇到复杂问题无法及时解决时，要给用户一个答复，提供暂时的替代方案或告知预计解决问题的时间，完成反馈闭环。同时要更新、分类和汇总后台新增反馈并提交给产品、技术处理，对高频问题保持重视并尽快推动解决。日常还需通过举办用户活动、发放专属优惠或折扣、发送push推送最新产品资讯等方式促活用户；与重点或特殊用户沟通、定向发送用户调查问卷以提升产品体验，并在沟通中深挖用户反馈背后的真实原因。在转化方面，持续输出产品优势和运营者的影响力，推动用户完成转化购买。此外，依据用户的购买偏好、购买频率、金额、最近消费时间等进行精细化分层，为用户精准推荐产品，并分析用户行为路径判断品类表现。在采用公众号、社群、企业微信等渠道的运营体系中，还需维护公众号推送、社群互动、企业微信专属客服、DM卡与一物一码扫码链路、朋友圈广告投放等事项，并通过价格、服务、福利、品牌联名与场景等多维度加持提升复购率。
- `it-ops-user-kp-071`［坑与经验］线上自营商城擅自压低20%-25%的业主返利比例，导致居家囤货无收益、复购率极低；CPS渠道未启用40%-50%的高返利优势，年轻人网购、外卖、出行消费无大额减免，无法感知模式价值。
- `it-ops-user-kp-029`［工作流程］第三阶段以朋友圈广告投放配合线下一物一码：利用流量明星和综艺在朋友圈为广告带量，将流量引流至公众号和小程序；线下升级为一物一码，扫码可领取优惠、玩游戏、加企业微信，并借助用户自发传播形成社群裂变。
- `it-ops-user-kp-053`［技能工具］用户行为报表
- `it-ops-user-kp-036`［技能工具］FAQ话术模板
- `it-ops-user-kp-074`［坑与经验］多数物业长期只做线下渠道，浪费CPS高比例增量权益和自营商城长效收益；或重线上轻线下，缺失刚需基础流量，三大渠道比例优势无法联动发挥，项目活跃度持续下滑，最终沦为摆设。
- `it-ops-user-kp-016`［核心职责］按安装时间对新老用户配置差异化广告策略：新用户保留少量高质量广告源、优先展示体验友好的广告样式、关闭激进样式并适当上浮底价；过渡期用户逐步放开广告频次和广告源数量；老用户恢复正常广告策略。
