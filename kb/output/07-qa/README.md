# 质检 Agent · 工作说明

**成果目录**：`kb/output/07-qa/`
**成果粒度**：每个岗位一份 —— `<岗位id>.md`

---

**什么时候调用**
- 入库 md 产出后，**每批抽 10%**（抽样比例定义于 `kb/pipeline.config.json` 的 `qaSampleRate`，试点想全检可临时设为 1）
- 结构化重做后需复检

**怎么工作**
1. 随机抽样
2. 逐条比对：结构化后的内容，在原文里能不能找到依据
3. 判定是否忠实，列出问题（位置 + 问题 + 严重度）

**要完成的任务**
守住「不脑补」这条底线，把凭空添加的内容揪出来退回。

**要输出什么东西**
`kb/output/07-qa/<岗位id>.md`（每个岗位一份）

内含：抽了哪几条、忠实 / 不忠实、问题明细、回退了哪些

**注意事项**
- **只判「内容有没有原文依据」，不判措辞是否与原文一致**（因为结构化已改写成书面语）
- 出现「严重」或「中等」问题即判不忠实
- 不忠实 → 退回结构化重做（≤2 次）；仍不通过则**保留并标记失败**，不删除、不隐瞒
- 不评判内容有没有价值、写得好不好
