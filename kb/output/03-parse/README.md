# 解析 Agent · 工作说明

**成果目录**：`kb/output/03-parse/`
**成果粒度**：每个岗位一份 —— `<岗位id>.md`

---

**什么时候调用**
- 采集 md 产出后，按岗位逐个跑

**怎么工作**
1. 正文文字直接取用
2. 正文不足 120 字 → 下载图片 → OCR（tesseract.js，`chi_sim`）
3. 合并为纯文本

**要完成的任务**
把该岗位的图文帖转成干净、可读的纯文本。

**要输出什么东西**
`kb/output/03-parse/<岗位id>.md`（每个岗位一份）

内含：每篇帖子的纯文本 + 该帖实际使用的解析通道（正文 / OCR）与 OCR 张数

**注意事项**
- **只转换、不改写、不总结**；OCR 结果只做空格与换行清洗
- 如实记录每条帖子用的是「正文」还是「OCR」，以及 OCR 张数
- OCR 不认识的字不许"猜"，宁可留错字并标注
- 上游已跳过视频，本阶段**不涉及视频**
