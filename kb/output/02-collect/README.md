# 采集 Agent · 工作说明

**成果目录**：`kb/output/02-collect/`
**成果粒度**：每个岗位一份 —— `<岗位id>.md`

---

**采集源**：搜狗微信搜索 `https://weixin.sogou.com/`（免登录，公众号文章）

**什么时候调用**
- 规划 md 产出后，按岗位逐个跑

**怎么工作**
1. 用 Chromium 打开搜狗微信搜索，按该岗位的关键词逐个搜索（`type=2` 文章搜索）
2. **每个关键词取前 15 条**（单页约 10 条，不足则翻到第 2 页补齐）
3. **只抓图文（公众号正文），视频号内容直接跳过**
4. 逐条打开文章详情页（搜狗跳转链接会自动落到 `mp.weixin.qq.com`），抓正文、标题、公众号名、发布时间、真实链接

**要完成的任务**
把该岗位相关的公众号文章抓成可解析的原料。

**要输出什么东西**
`kb/output/02-collect/<岗位id>.md`（每个岗位一份，给人看）
`kb/output/02-collect/<岗位id>.json`（机器可读副本）

内含：用了哪些关键词 / 每个词命中多少条 / 文章清单（标题、公众号、时间、链接、正文）/ 跳过与失败记录

**注意事项**
- **前 15 条**，不做全站爬取，只采公开文章
- 视频号跳过，并在 md 里写明「已跳过 N 条」
- 单条失败记录后继续，不中断整批
- 每条之间留等待间隔（频控）；搜狗会限频 / 弹验证码，遇到验证码停下来找用户，**不做风控绕过**
- 详情页正文抓取失败时降级用列表页摘要，保留原文链接供溯源
