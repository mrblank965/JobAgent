# 规划 Agent · 工作说明

**成果目录**：`kb/output/01-plan/`
**成果粒度**：全量一份 —— `岗位清单.md`

---

**什么时候调用**
- 每次运行的第 1 步
- 只在「用户改了覆盖范围」时才重跑

**怎么工作**
1. 归纳金融（银行 / 证券投行 / 基金资管 / 保险 / 互金）与互联网（运营 / 产品 / 数分 / 风控）的**常规岗位**
2. 每个岗位列出它在 **JD 上的常见不同名称**（同一岗位的不同叫法）
3. 每个岗位列出**用户会在小红书搜它时用的关键词**
4. 合并去重，输出岗位清单

**要完成的任务**
给出一份「值得拆解的常规岗位清单」，并带上每个岗位的别名与搜索关键词。

**要输出什么东西**
`kb/output/01-plan/岗位清单.md`（**唯一交付物**）

每个岗位一节，含：岗位名 / 行业 / 方向 / **JD 常见别名** / **搜索关键词**

固定格式（供采集 Agent 程序化解析）：

```
## <岗位id>
- 岗位名：银行客户经理
- 行业：金融
- 方向：银行
- JD 常见别名：理财经理 | 个贷客户经理 | 对私客户经理 | 财富顾问
- 搜索关键词：银行客户经理日常 | 银行客户经理劝退 | 银行客户经理真实工作 | 银行客户经理业绩压力
```

**注意事项**
- **不做 P0/P1/P2 优先级**
- 只列**常规岗**（大众常搜、常被拆的），不列冷门小众岗
- 别名要真实，例如客户经理 → `理财经理 / 个贷客户经理 / 对私客户经理 / 财富顾问`
- 关键词要口语化、贴近真实发帖语气，每岗位 3-5 个
- **别名行与关键词行必须用固定格式**（`|` 分隔），否则采集 Agent 无法自动解析
