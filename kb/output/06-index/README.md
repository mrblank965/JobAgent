# 入库 Agent · 工作说明

**成果目录**：`kb/output/06-index/`
**成果粒度**：每个岗位一份 —— `<岗位id>.md`

---

**什么时候调用**
- 结构化 md 产出后，按岗位逐个跑

**怎么工作**
1. 按岗位聚合知识点，**去重**（同一意思只留一条）
2. 生成知识点唯一 ID（`kpId`）
3. 建检索索引：岗位名 / 别名 / 关键词 → 岗位
4. 落来源链：原文链接 → 清洗文本 → 结构化内容 → kpId

**要完成的任务**
把知识点变成**可检索、可溯源**的知识库。

**要输出什么东西**
- `kb/output/06-index/<岗位id>.md`（每个岗位一份，人可读的知识库条目）
- `kb/store/`：索引文件 + 来源链（机器用，不放在 output 里）

**注意事项**
- 同一知识点去重（帖内 + 跨帖）
- **来源链字段固定不可增删**，每条知识点必须能反查到原文链接
- 索引必须支持「岗位名 / 别名 / 关键词」三种召回
- 向量层可替换：换 embedding 只改向量化那一步，其余流程不动
- 若本次没用向量检索（降级关键词），要在 md 里写明
- **来源链落盘由本 Agent 负责**（总控不落盘）
