# 券商财富管理投资顾问（fin-sec-wealth-advisor）

> 结构化 Agent · 2026-10-29 · 基于 2 篇帖子整合 · 已改写为书面语

**岗位别名**：投资顾问、财富管理顾问、理财经理

## 核心职责

- 开展基金投顾业务，为客户提供资产配置建议和投资组合管理服务。
- 根据客户的投资目标（如追求流动性、保值、增值、高收益）匹配相应的策略产品。
- 了解客户需求，进行适当性匹配，提供人性化的投顾服务。
- 参与基金池出入库、基金组合调仓等投资决策，需经基金投资决策委员会同意。
- 防范利益冲突，确保与基金销售、自营、托管等业务隔离，关键岗位专人专岗、独立考核。
- 在总部筛选基金并打包成投顾产品后，承担一线销售任务，完成摊派的指标。

## 工作流程

- 公司层面成立基金投资决策委员会，统一集中管理投研投顾、合规风控等关键节点，包括基金池出入库和基金组合调仓。
- 经管委下设基金投资顾问业务中心，设立投资研究、投资顾问、交易运营管理等专人专岗。
- 初期通过内部调岗和外部招聘搭建基金投顾团队，后续根据业务规模增加人员。
- 投顾服务前了解投资者需求，匹配适当性，再配置策略。
- 投资决策中，单个客户持有单只基金比例不得超过20%，所有客户持有单只基金比例不超过10%等风控要求。
- 将公司及关联方管理或托管的基金纳入系统监控，及时防范利益冲突。

## 坑与经验

- 基金投顾业务商业模式不清晰，投顾费率在0.2%至0.5%之间，券商做投顾总体上不赚钱，现有规模下收入尚不足支撑业务开展，机构转型商业驱动力不足。
- 基金投顾走向产品化，总部筛选基金打包成投顾产品后给一线销售摊派指标，顾的环节普遍缺失，即使有也是泛泛的、标准化的，投顾又回到卖产品、堆规模的老路。
- 投顾客户人均资产投入较少，长尾客户居多，很多客户只是试试水，人均投入约两万元。
- 即使偏股型基金投顾大多数能跑赢沪深300，但大多数投顾账户还是亏损。
- 市场下行期，单只权益基金客户留存率在四五成就不错了，投顾能做到七成留存率已属不易。
- 券商与客户存在利益冲突，因为券商同时从事经纪、投行、公募子公司等业务。
- 基金投顾业务从0到1突破简单，从1到10增长很难，过去一年券商基金投顾基本停滞。
- 规模涨到百亿时普遍遇到瓶颈，未来能否保持增长存疑。
