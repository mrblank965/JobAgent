# 基金产品经理（fin-fund-product-manager）

> 结构化 Agent · 2026-10-29 · 基于 5 篇帖子整合 · 已改写为书面语

**岗位别名**：公募产品经理、基金产品设计、产品经理

## 核心职责

- 根据公募市场趋势、投资者需求及公司业务禀赋，进行公募产品的研究论证与开发工作。
- 完成基金申报材料的撰写、申报、审批及产品成立后的全生命周期管理及维护工作。
- 跟踪国内外资产管理行业发展情况、最新监管政策及同业产品竞争趋势，撰写研究报告，为公司产品布局提供支持并创造价值。
- 参与公司公募产品战略规划，为公司业务发展提供方向和建议。
- 负责资管基金产品管理领域数字化建设的产品规划、业务分析、功能设计，包括产品生命周期流程管理、产品主数据管理、产品创新分析等业务方向。
- 跟踪金融科技发展趋势，结合公司战略形成并推动本领域业务规划及产品需求的研发落地。
- 负责将业务需求转化为可执行产品方案，绘制产品原型图、产品流程和交互设计、编写相关需求说明书。
- 沟通协调技术研发团队，做好日常项目进度跟进，确保产品功能特性和交付符合要求，推进产品目标的达成。
- 负责与业务管理部门的持续紧密沟通，开展跨部门需求调研与梳理，有效促进业技融合工作并持续提升产品管理核心业务智能化水平。
- 进行产品交易结构的设计。
- 寻找托管机构，不同类型的基金产品托管与监管不同，契约型基金必须在托管机构直接开户，需有托管银行机构。
- 对于契约型基金，在找到托管机构之后，修改托管机构提供的合同模板。

## 工作流程

- 根据市场趋势、投资者需求及公司业务禀赋进行产品研究论证与开发。
- 撰写基金申报材料并完成申报、审批流程。
- 产品成立后进行全生命周期管理及维护。
- 跟踪行业发展和监管政策，撰写研究报告支持产品布局。
- 参与公募产品战略规划。
- 进行产品交易结构设计。
- 寻找托管机构并完成开户。
- 修改托管机构提供的合同模板。
