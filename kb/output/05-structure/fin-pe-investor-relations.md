# PE基金募集/投资者关系（IR）（fin-pe-investor-relations）

> 结构化 Agent · 2026-10-29 · 基于 27 篇帖子整合 · 已改写为书面语

**岗位别名**：投资者关系经理、IR经理、基金募集经理、募资经理

## 核心职责

- 基金募集：制定并执行基金募资计划，主责推进基金募集相关工作，包括新基金募资、专项基金、跟投资金、单项目资金募集工作。
- 投资者关系：拓展、维护、整合LP资源，研究并响应LP投资需求；负责投后日常对接、系统填报、返投牵头落实，建立长期合作关系。
- 基金运营：负责部分公司存续基金的运营工作。
- 主导募资全流程：LP触达与路演、尽调配合、认购、KYC/AML审查、协议签署与交割，确保高效合规。
- 开拓香港及亚太LP渠道（家办、机构、母基金、香港高校、保险及主权基金等），维护长期关系，负责定期报告、LPAC及年度大会，并反馈LP意见。
- 配合基金设立、牌照合规及内外部协作，支持项目路演与被投企业国际化，跟踪香港家办政策与税务优惠。
- 参与基金募集策划和产品方案设计，制定可行性募资方案，撰写基金募集文件，组织基金路演等。
- 负责开拓、联络基金投资人，包括但不限于各类市场化母基金、引导基金、上市公司、第三方财富管理公司、高净值个人投资者等。
- 完成信息收集、渠道拓展、资源对接、材料准备、LP谈判及基金管理等工作。
- 负责基金的投资人关系维护、投后管理等工作。
- 独立承担募资任务：主动开拓各类人民币LP资源，完成资金对接、谈判、尽调、签约、打款、落地关账全流程，确保募资任务按期完成。
- 全渠道LP资源开发与维护：自主开拓市场化母基金、政府引导基金、产业资本、上市公司、家族办公室、高净值机构、三方资金等各类LP渠道；建立自有优质LP资源池，持续盘活存量、开发增量，提升复投率、转介绍率，支撑持续募资。
- 存量LP存续管理：负责存续LP日常维护、定期信息披露、业绩沟通、项目走访组织；通过优质存续服务挖掘存量LP新增出资、二期基金复投、产业协同、资源转介绍，将存量服务转化为募资增量。
- 募资材料与市场研判：持续跟踪一级市场募资行情、LP出资偏好、政策变化，定期输出募资复盘与策略优化方案，配合团队调整募资节奏与打法。
- IR工作指向“募投管退”的募资环节，工作主要包括两部分：一是基金募资（机构合伙人通常是募资第一主力），二是投资者关系的日常维护和信息披露。
- IR基本负责基金全流程工作。
- 当前有不少机构要求募资到地方引导基金的IR，来主要负责地方返投的跟进，干起了收尾工作——“招商”。
- IR投入最多的工作却是在退出端，忙着做重组，忙着找并购机会，与此同时，招引的活也一项不落。
- IR随时待命，响应老板的IR诉求，写募资材料，pitch新LP，给老LP写报告。
- 协助MD进行赛道扫描与覆盖，主动发掘和推进项目，开拓次级赛道及标的。
- 主导开展企业深度业务DD，协同三方机构完成法律和财务DD。
- 负责份额锁定、条款制定与商业谈判，撰写PreIC/IC报告并准备汇报，推动交易进程。
- 负责投后跟踪与季度投后报告，并支持路演、材料归档、融资条款审核、上市材料准备等团队日常事务及上级交办事项。

## 工作流程

- 基金募集流程包括：制定募资计划、撰写基金募集文件（如Teaser、PPM、DDQ、业绩模型及路演材料）、组织路演、LP触达与路演、尽调配合、认购、KYC/AML审查、协议签署与交割。
- IR需要完成从资源对接、谈判、尽调、签约、打款到落地关账的全链路。
- 日常需进行LP日常维护、定期信息披露、业绩沟通、项目走访组织。
- 持续跟踪一级市场募资行情、LP出资偏好、政策变化，定期输出募资复盘与策略优化方案。
- 配合基金设立、牌照合规及内外部协作，支持项目路演与被投企业国际化。
- 负责部分公司存续基金的运营工作。
- IR基本负责基金全流程工作。
- 当前IR投入最多的工作在退出端，包括做重组、找并购机会，同时负责地方返投的跟进（招商）。
- IR随时待命，响应老板的IR诉求，写募资材料，pitch新LP，给老LP写报告。

- 具备私募基金从业资格证。
- 持CFA/CPA或香港持牌背景者优先。

## 典型的一天

IR的日常工作包括随时待命响应老板的IR诉求，撰写募资材料，pitch新LP，给老LP写报告；同时投入大量时间在退出端，忙着做重组、找并购机会，并负责地方返投的跟进（招商）。此外，还需进行LP日常维护、定期信息披露、业绩沟通、项目走访组织，持续跟踪一级市场募资行情、LP出资偏好、政策变化，定期输出募资复盘与策略优化方案。在募资酒桌上，IR要做到眼观六路、耳听八方，领导没酒了要第一时间倒上，领导举杯了要第一时间起身敬酒。

## 坑与经验

- 人民币基金招IR有的要求能喝酒，酒桌上要眼观六路、耳听八方，领导没酒了要第一时间倒上，领导举杯了要第一时间起身敬酒。
- IR圈有一个不成文的规定，最好性别为女。
- 美元基金招IR要求候选人最好高中或者中学在美国读书，以便更了解美国文化，能跟美国LP聊得来。
- 一些人民币基金招IR要求有在体制内工作的经验，需要找到能和人民币基金LP同种语言和圈子的人。
- IR工作没有明确的量化机制，薪资结构也不完善，辛苦大半年，最终到手多少全看老板心情。
- 不同机构的人民币IR薪资结构仍无统一标准，相异很大。
- IR人才十分紧俏，100个招聘需求可能对应10个候选人，机构着急用人时开出的涨幅可达40-50%甚至翻倍，今年出现了不少外部新人薪资倒挂的情况。
- 人民币募资本身就是个比美元辛苦数倍的工作，其复杂性也会随基金体量指数性增长。
- 人民币LP市场非常分散，每类LP的关注和诉求都不一样，需要大量的沟通成本以及差异化的人员和策略。
- 险资对IR要求较高，有相关对接经验的IR恐怕不过百人。
- IR经常面临“假装在募资”的困境，出差付出200%的辛劳，却很难达成有1%的进展。
- IR可能被要求转岗或降薪，甚至面临裁员风险。
- IR工作内容细碎、烦琐，基本不算纯粹的PR工作，消耗时间，需要体力。
- IR需要身兼数职，无缝切换，工作内容包括IR、PR、投后管理等。
- IR可能被要求负责地方返投的跟进，干起招商工作。
- IR可能被要求参与退出工作，忙着做重组、找并购机会。
- IR需要接受高频出差、高强度工作节奏。
- 募资成功与否是综合性结果，主要决定因素有三个：基金品牌、历史业绩和募资人员，三者缺一不可。
- 过去机构募资太轻松了，凭着几个明星案例或者合伙人名气就能轻松募到资金，但现在基本不可能了。
- 人民币募资也在不断撞车，大人民币LP的办公室里，GP的拜访早已前脚接着后脚。
- IR需要面对LP结构复杂、产业理解门槛高、政策敏感度高等行业痛点。
- 签LPA时容易出错，公司签署版本和个人签署版本并不相同，每份都要签字近40次。
- IR圈内卷严重，招聘条件越来越个性化，如要求候选人最好高中或者中学在美国读书、有体制内工作经验、能喝酒等。
- 能达到160万年薪的IR凤毛麟角，大多数人无法满足机构对优质IR的要求。
- IR需要具备囊括业内大多数LP的信息情报网、能跟LP实实在在搭得上话、可以尽可能缩短LP决定投资的时间等能力。
- 一些机构选择躺平或摆烂，募资难、投资难、招人更难。
- IR工作可能被边缘化，品牌部在投资机构内部只是一个辅助部门。
- IR需要接受薪资调整，甚至降薪以保住工作。
- IR可能面临工作加量不加价，老板不定期想裁员，工作内容没有成就感、价值感，没有上升空间。
- 职场女性难以兼顾工作和生活，所谓的平衡只是强撑或有父母支持。
- IR需要应对LP的追债和项目退出难的问题。
- IR需要协助被投企业找外部资源和资金，有时干起了FA的活。
- IR需要执行走进大企业等活动，从对接嘉宾到邀请创业者、设计活动流程、邀请媒体、写活动稿等全部一人完成。
- IR的工作量细碎、烦琐，基本不算纯粹的PR工作。
- IR需要维护的媒体关系就那么几家，也没什么负面新闻，但工作环境已不如以前peace。
- IR需要面对行业变化，如裁员、降薪、转换赛道、拥抱国资等。
- IR在主业混保低薪资，副业寻找新机遇，成为行业内的人默认的生存方式。
- IR群内有的小姑娘兼职做被投企业的PR，赚取外快。
- 副业做保险的PR最多。
- 在小红书做博主的PR也不在少数。
- 生完孩子后社交能力强的PR做起了母婴自媒体。
- 合伙人并不傻，谁会开着工资容忍员工做副业呢。
- IR需要重新思考职业规划，或许做一家公关公司是新出路。
- 离开，现在并不是时候，外部环境的动荡让IR没有随意离开的勇气。
- 在投资机构做PR是一份光鲜且无聊的工作，光鲜的是与一群顶级聪明的人一起工作，能见到创投圈行业大佬，无聊的是日常PR、日常组织活动。
- 品牌部在投资机构内部也只是一个辅助部门，认清现实，会减少内心的落差。
- 尽管当下苟着的日子，如鱼刺哽喉般难受，还要挺住。
