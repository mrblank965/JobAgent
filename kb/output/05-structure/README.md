# 结构化 Agent · 工作说明

**成果目录**：`kb/output/05-structure/`
**成果粒度**：每个岗位一份 —— `<岗位id>.md`

---

**什么时候调用**
- 清洗 md 产出后，按岗位逐个跑

**怎么工作**
1. 汇总该岗位所有被保留的文本
2. 把原文**改写成自然、严谨的书面语句**——去掉口语、语气词、网络用语、emoji
3. 按五类归档：核心职责 / 工作流程 / 技能工具 / 典型的一天 / 坑与经验
4. 全书统一风格（同一套句式与用词习惯）

**要完成的任务**
把该岗位的多篇帖子整合成一份**风格统一的岗位知识**。

**要输出什么东西**
`kb/output/05-structure/<岗位id>.md`（每个岗位一份）

内含：岗位名 / 别名 / 五个分类下的内容 / 末尾列来源帖子链接

**注意事项（本 Agent 规则改动最大）**
- **允许改写措辞**：从原文内容出发，写成自然严谨的风格，**不要口语化**
- **不再要求原文原句**（取消逐字 evidence）
- **仍然不许脑补**：只写原文出现过的内容；某一类原文没提到，就写「暂缺」，不许用岗位常识补
- 风格要统一：同一份 md 内不要一半书面一半口语
- 溯源方式改为**末尾列来源帖子链接**（替代原来的原句 evidence）
- 不做跨帖矛盾调和：两个帖子说法冲突时，两个都列出来并标注来源
