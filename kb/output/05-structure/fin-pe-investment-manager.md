# PE投资经理（fin-pe-investment-manager）

> 结构化 Agent · 2026-10-29 · 基于 36 篇帖子整合 · 已改写为书面语

**岗位别名**：投资经理、PE投资分析师、私募股权投资经理

## 核心职责

- 对团队拟投资的一级市场项目进行现场调研和分析
- 为团队寻找和筛选有发展潜力和投资价值的投资标的和机会，获得投资项目
- 参与拟投项目的谈判、尽调及投资方案的设计
- 参与项目最终投资的决策以及负责项目的具体投资实施
- 对已完成的投资项目负责进行后续监控、分析、评估、管理及基金退出安排
- 负责医药/器械/医疗服务相关产业研究、趋势跟踪、潜在投资标的挖掘
- 参与投资项目尽职调查，完成尽调报告、估值模型及投资建议书
- 协助投资谈判、交易架构设计及投后管理工作
- 对在市场上还没有上市的公司里，找一些成长性比较好，价格估值合理的标的进行少数股权的投资
- 看很多公司，去分析它的业务，看成长性，并且进行估值
- 前期接触：跟公司管理层聊业务，了解整个行业的情况，带着下面的小朋友做一些行业研究
- 管理层访谈：前期接触后，如果觉得标的对自身估值有较好预计，安排管理层访谈，有一大部分工作是开会
- 上会汇报：综合desk research和访谈结果，推进上会汇报工作，上会材料以PPT形式覆盖公司、行业及财务相关的主要问题，获得投委会委员投票通过
- 法律谈判：上会通过后，进入法律谈判，与会计师和律师一起工作
- 寻找优质项目及以合适的价格拿到合适份额
- 行业调研：通过对于行业过去、当下及未来发展趋势的了解及分析，获取有价值的信息为投资决策提供依据
- 前期做一些简单的项目筛选，然后参与项目的尽职调查
- 投后管理：VC注重投后管理，主要是资金、人力、战略及行业资源方面提供支持；PE投后管理主要以监督为主及部分资源协调
- 项目退出：投资一个项目时考虑后续退出路径，常见退出方式包括IPO、企业被收购、老股转让、企业管理层回购等
- 负责推进投资管理体系的运营，基于投资协议和BCA条款对投资公司进行日常管理及服务
- 对接内部产品和商务资源，形成对外输出能力包，与投资公司群体形成增值互动；完善投资管理体系，优化投资管理工具
- 基于战略投资需求，输出投资建议报告，协同集团投资体系，推动项目落地并跟进项目实施
- 投中环节：尽调、估值建模、投决报告
- 财务尽调：包括前期准备、现场访谈及取证、分析及形成判断三个阶段

## 工作流程

- 项目获取：主要通过身边的朋友及FA获取项目为主；新成立的基金还会到中介机构拜码头，希望财务顾问多多推荐项目；政府信息也是私募基金猎物的一个重要来源
- 初步接洽与筛选：先线上电话聊一聊，快速判断项目要不要跟进，如果不跟进就不需要去出差
- 前期接触：跟公司管理层聊业务，了解整个行业的情况，带下面的人做行业研究
- 管理层访谈：如果觉得公司对自身估值有较好预计，安排管理层访谈
- 上会汇报：综合desk research和访谈结果都不错的话，推进上会汇报工作，上会材料以PPT形式覆盖公司、行业及财务相关的主要问题，获得投委会委员投票通过
- 法律谈判：上会通过后进入法律谈判，与会计师和律师一起工作
- 尽职调查：参与拟投项目的谈判、尽调及投资方案的设计；财务尽调包括前期准备、现场访谈及取证、分析及形成判断三个阶段
- 投资实施：参与项目最终投资的决策以及负责项目的具体投资实施
- 投后管理：对已完成的投资项目负责进行后续监控、分析、评估、管理及基金退出安排
- 项目退出：投资时即考虑后续退出路径，常见退出方式包括IPO、企业被收购、老股转让、企业管理层回购等
- 基金内部考察程序：先由副总带队投资经理考察，然后向合伙人汇报，合伙人感兴趣以后上投资决策委员会投票决定；一个项目从初步接洽到最终决定投资，短则三月，长则一年
- 投中环节流程：AI搭结构，人填数据，人审核；结构问AI要，数据在本地填，全程不经过AI，产出人复核之后才能用

## 技能工具

- PPT
- Excel
- DCF模型
- 敏感性分析
- 可比公司估值表
- 尽调清单
- 访谈提纲
- 投决报告
- AI工具（用于生成尽调清单初版、访谈提纲、整理纪要初稿、搭建DCF框架、写公式、出敏感性分析结构、整理可比公司数据、生成报告初稿、文字润色、PPT大纲）
- 录音本地转文字工具
- 企查查等公开信息渠道
- 万得

## 典型的一天

弹性工作制，一般8-9点左右开始工作，晚上8-9点可以从office走，但是回家可能也会再做一点。具体还是看整个项目节奏，以做完工作为主，没有什么强制要求。如果项目特别紧张的话，白天会开很多会，晚上就可能熬夜。工作强度还是看项目和老板推进节奏。出差相对咨询比较少，主要是前期快速筛选和判断比较准确，确认推进的项目会安排集中几天去出差，完成必要的访谈。如果只是第一次见面的话，可能先线上电话聊一聊，快速判断这个项目要不要跟进，如果不跟进的话就不需要去出差。近期一直没什么周末。

## 坑与经验

- 投资经理是机构里冲在最前线的执行者，时常会面临新领域、新模式的挑战，需要掌握很好的学习力
- 大部分投资经理在业内的人脉并不多，而且因为缺少话语权，FA一般推项目都不会推送给投资经理，效率比较低下
- 很多机构对于投资经理有一些项目指标，每一个月或者季度需要寻找多少优质的项目，至于投不投其实由投委会说了算
- 投资经理行业经验很有限，对于项目的分析能力一般，主要的工作还是在于寻找项目，做行业调研，前期做一些简单的项目筛选，然后参与项目的尽职调查
- 行研报告工作量挺大，PE/VC机构的人一般并不是很多，很多行业报告写的大多是东拼西凑的信息
- 如何抢到优质项目的份额，要看机构自身的实力及背书，投资经理起到的作用不是很大
- 早期投资挺难做的，因为初创项目缺少数据、商业模式没有经过市场验证，分辨项目非常困难，对于投资经理而言困难则更大
- 大部分初创企业创始人在投融资方面知识很薄弱，沟通成本很高，很多创始人觉得自己的公司很棒，但事实并非如此
- 初创企业虽然数量庞大，但真正优质的并不多，而且因为初创企业早期名声不大，要从中寻找出优质的项目很困难
- 初创企业能够成长起来的不多，即使最后成长起来，需要的时间周期也会比较长，要做好长期陪伴的打算
- PE接触的大部分是比较成熟的企业，企业管理层一般经验比较丰富，资方话语权不是很大，企业管理层也不太愿意资方过度参与
- 投资这个行业按理是一个越老越值钱的行业，但是如今的行业格局明显，很难产生新的巨头，新人想要升职也比较困难
- 现在行业越来越卷了，不管是FA还是PE/VC竞争都非常激烈
- 投资经理几乎毫无前途可言，其在投资机构里的工作内容基本都是收集项目信息、做行业分析PPT、对接FA投递的项目做基础判断、投后资源支持等基础工作；如果想参与投资决策，要再熬个六、七年的时间争取升到VP以上
- 从分析师或投资经理岗位5-6年晋升成为合伙人的，在业内定是属于一段佳话，说明这位投资经理创造了传奇的业绩
- 晋升合伙人除了投资业绩，还需要有特长，融资能力、项目资源能力、政府关系能力、行业的洞察能力，起码有一项优于其他人
- Carry需要熬出来，企业从创业融资到上市往往需要8-10年时间，大部分的投资经理很难坚持到企业上市、基金退出
- 没有Carry的时候从业人员的薪酬结构是基本工资加年度奖金，大约是2万左右的基础薪资，工作状态近乎随时工作，创始人半夜有时间就半夜飞过去聊项目，一个错过就错过一个独角兽
- 能留在VC/PE的人要么是不差钱的，要么是热爱行业的，想要挣快钱的人并不适合这个行业
- AI生成的尽调清单看着面面俱到，行业/公司特有的关键问题反而容易漏，要对照检查
- AI搜集的公开信息，要按核实铁律回原文核对
- 现场感AI代替不了，车间开工情况、仓库库存、员工精气神，只有到了现场才知道
- AI拿不到回避、犹豫、语气等现场信号，对方为什么回避、接下来怎么应对，是人的判断
- 交叉验证的临场反应只有人能做到，访谈是实时的，现场听出矛盾当场追问只有人能做到
- 估值假设设定是判断不是计算，AI能给参考区间，但区间本身会锚定判断，取数要自己拿主意
- 财务预测核查，AI列得出核查清单，做不出核查判断
- 估值结论拍板，模型只是计算器，喂什么假设出什么数，数能不能信取决于假设的扎实程度，AI给不了这些判断
- 投决报告的取舍的度，投资亮点写哪几个、怎么排序，风险披露到什么程度，AI不了解本机构，把握不了取舍的度
- 上会的分寸感在亲历者的脑子里，每家投委会都有自己的决策习惯，来自一次次上会的经验积累
- AI的书面语是通用款，公司内部的惯用语言和口径，需要人来判断和修改
- 财务尽调中对于明显的财务造假要坚持底线
- 财务分析要始终与业务及行业的调研保持高度一致，财务不能脱离具体行业及业务
- 财务分析要围绕合规性以及成长性两个关键要点进行
- 外部审计报告一定要获取盖章正式版，并通过与会计师沟通、查阅审计调整分录、复核审计收费等方式综合判断审计的工作标准
- 科目余额及序时表一定要获取最明细的版本
- 采购台账、销售台账越详细越好
- 对于个别资金链紧张的公司，贷款合同及贷款卡信息很重要，比如识别是否存在民间高利贷
- 与审计师的交流是最有效的发现企业财务问题的方式，因为审计师在现场的时间、人手远比PE机构多得多
