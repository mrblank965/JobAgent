# 保险理赔（fin-ins-claims）

> 结构化 Agent · 2026-10-18 · 基于 26 篇帖子整合 · 已改写为书面语

**岗位别名**：理赔专员、理赔查勘、核赔岗、理赔审核

## 核心职责

- 全流程理赔受理与调度：接报案、信息登记、情绪安抚、现场调度，指导客户留存证据、规范处理事故。
- 查勘定损与事实还原：车险现场查勘、人伤走访核实、医疗病历审核、财产损失勘验，还原事故真相，核定损失范围与金额。
- 资料审核与合规判定：审核保单有效性、资料真实性、责任归属，对照条款与法律判定是否赔付、赔付比例。
- 赔款理算与支付跟进：计算赔付金额、走完核赔流程、跟进打款时效。
- 反欺诈与风险防控：识别虚假报案、夸大损失、伪造票据、冒领理赔等欺诈行为。
- 纠纷协调与客户服务：解释条款、沟通结果、处理异议、协同法务与调解机构。
- 案件归档与数据沉淀：整理案卷、复盘典型案例、沉淀风险数据。
- 日常理赔数据质检与分析：关注案均赔款、出险频度等指标，对异常地区、险种、渠道、人员展开排查。
- 协助客户收集理赔资料：陪同或替客户提取病历，约时间上门收集整理资料，亲自将理赔资料送往保险公司以提升时效。
- 向客户及代理人解释理赔相关名词与条款，如意外伤害事故、猝死、等待期、宽限期、既往症、如实告知等。

## 工作流程

- 报案受理：客户出险后通过客服电话或APP报案，理赔人员登记信息、安抚情绪并指导留存证据。
- 现场查勘：对需要查勘的案件安排查勘员前往事故现场或医院，核实事故真实性、确认劳动关系、评估损失程度、防范保险欺诈。
- 资料收集与审核：客户提交索赔资料（保单、身份证明、诊断证明、病历、票据等），理赔人员审核资料齐全性与真实性。
- 责任判定与理算：对照条款与法律判定是否属于保险责任、赔付比例，计算赔付金额。
- 核赔与支付：走完核赔流程，跟进打款时效，确保应赔尽赔、快速到账。
- 拒赔处理：出具书面拒赔通知书并写明法律依据；客户有异议时进行沟通解释或引导投诉、调解、诉讼。
- 案件归档与复盘：整理案卷、复盘典型案例、沉淀风险数据。
- 农险理赔流程：受灾后24小时内报案（最晚不超过48小时），通过APP或客服电话说明姓名、种植地址、受灾面积及灾害类型；理赔人员现场查勘时陪同指认边界、提供土地承包合同复印件；定损后提交身份证、一类银行卡、保单、现场照片及村委会种植证明；赔款=每亩保额×生长期赔付比例×受灾面积×（1-免赔率）。

## 技能工具

- 理赔核心系统
- 移动查勘APP
- 医疗/交管数据联网平台
- 反欺诈模型
- 定损知识库
- 快保APP（好赔服务委托入口）
- 保险公司APP、小程序（农险报案可实时定位、留痕）

## 典型的一天

理赔岗位分为内勤审核岗、车险查勘岗、健康险/寿险核赔岗、财产险专项岗及第三方公估机构等场景。内勤岗位工作节奏相对规律，外勤岗位需随时响应现场查勘。日常工作中，理赔人员依规办事、据实定损、精准核算、耐心沟通、坚守原则。以好赔专员为例，其一天可能包括：接到客户出险信息后主动去医院探视，陪同或替客户提取病历，与客户约好时间地点上门收集整理资料，亲自将理赔资料送往保险公司以提升时效；遇到客户年纪较大没有银行卡，需陪同客户办理银行卡；客户工作繁忙时，需乘车前往客户工作地点整理审核资料。案件处理过程中需研读条款细节，弄懂理赔明细中每一个数字背后的意义，结案后对照条款核对理赔金额是否合理，帮助拒赔客户向保险公司了解详细拒赔理由。

## 坑与经验

- 划痕险常被业务人员或修理厂当作“福利险种”，在保单年度内想尽办法将保额用光，利用自助理赔通道客户自助拍照时用光线和角度拍出有损失的照片；若保险公司要求扩损，则利用其他车辆扩损并且只拍局部不拍整体；甚至在网上购买相关设备伪造划痕损失。
- 团伙作案“窝案”案均赔款较低、出险频度较高，反欺诈效果受工作人员经验影响极大。
- 客户作为非专业人士，收集理赔资料时容易收集不全或出现遗漏和误差，给理赔带来不必要的麻烦。
- 部分保险公司故意把“诉讼时效”偷换成“理赔申请时效”，以超过2年或5年为由直接拒绝受理理赔申请；诉讼时效届满只是丧失胜诉权，实体理赔请求权依然存在。
- 晚报案、晚提交理赔不等于直接拒赔，只有因拖延导致事故原因、损失情况查不清楚，保险公司才可以对无法查清的部分不赔。
- 保险公司可能仅口头给出赔付方案，不出具加盖公章的书面核定意见，也不公开误工费、护理费的计算标准，试图压低或搁置理赔。
- 保险公司可能主张雇主责任险赔付后要抵扣车上人员责任险赔款，但两类保险的保险标的、法律责任不同，并非重复保险，无权单方抵扣。
- 伤情较重可能构成伤残时，不要随便签一次性结案协议，避免放弃后续伤残赔偿金、二次手术费索赔权利。
- 营运货车司机误工费容易被按普通临时工标准压低，护理费核定也可能低于法定赔偿标准。
- 保险公司可能诱导客户签署“一次性了结/放弃其他权利”的和解协议；签字不等于必然放弃权利，但需在法定期限内以重大误解、欺诈、胁迫或显失公平为由请求撤销，超过除斥期间则撤销权消灭。
- 健康告知直接决定未来能否理赔，糊里糊涂全填“否”或过度告知都可能埋下拒赔隐患；体况不清晰时应走智能核保或人工核保流程。
- 医疗险、意外险续保需手动确认，以为自动扣费就是续上了，可能导致第二年保单已停而不知。
- 在互联网平台自行购买保险后缺少服务，责任过时无人提醒，理赔流程无人指导，病历怎么写、发票怎么开全靠自己摸索。
- 重疾险理赔严格按照条款约定事项进行，确诊即赔的病种约占10%，约30%需实施某种手术才能赔，近60%需病情达到约定状态才能赔付；医生眼里的“大病”不等于合同里的“重疾”。
- 自闭症理赔中，保险公司可能以“孤独症是先天精神疾病属于免责范围”或“确诊时年龄太小不符合条款要求”为由拒赔；收到拒赔通知不要签任何文件，可保留材料通过维权争取。
- 水稻农险中，蓄洪区、行洪区等禁止保障区域内种植，种植未经审定品种或投保时苗情已濒临枯萎，投保面积与遥感实测面积不符，均可能被拒赔。
- 水稻农险中，施肥、用药浓度超标等管理不当致损不予赔付；受灾后未等待查勘即自行翻耕、补种导致损失无法核定，将直接拒赔。
- 农业保险遵循损失补偿原则，重复投保无法获得双份赔款，仅由各承保公司按比例分摊，多余保费属于无效支出，还可能涉及骗保嫌疑。
- 车险中酒驾、醉驾、毒驾，无证驾驶、驾照过期或准驾不符，车辆未年检，事故后逃逸，故意制造事故骗保，改装车辆导致事故直接相关等情形，商业险可能拒赔。
- 附加新增设备损失险仅对“发生机动车损失保险责任范围内的事故”造成的新增设备直接损毁承担赔偿；若近因属于车损险责任免除（如人为划痕），车衣损失不属于该附加险保险责任。
- 理赔争议处理一般默认为诉讼方式，短期保险（一年期）诉讼时效为2年，长期保单为5年，超过时效不再受理。
